# SWAGGLauncher — официальные обновления

Это **публичный канал релизов** Minecraft-лаунчера SWAGGLauncher.

- [Скачать последнюю готовую версию](https://github.com/tsema702-lang/swagglauncher-peleases/releases/latest)
- `swagglauncher_Setup.exe` — установщик Windows.
- `swagglauncher_Update.zip` — архив автоматического обновления (скачивается внутри лаунчера).
- `swagglauncher_Update.sha256` — контрольная сумма SHA-256.

Готовые релизы собираются автоматическим Windows workflow из **приватного** исходного репозитория. Исходный код и личные настройки пользователей здесь **не публикуются**.

Если страница Releases пока пуста, готовая версия ещё не опубликована. Для версии 3.0.0 потребуется один раз установить новую версию с поддержкой автообновления; последующие версии смогут обновляться внутри приложения.

SWAGGLauncher — сторонний проект, не связан с Mojang Studios или Microsoft.
